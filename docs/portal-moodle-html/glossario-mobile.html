📖 Glossário Oficial de Termos de Desenvolvimento Mobile (id=29912 — 40 Termos A–Z)

Extraído integralmente da visualização completa (hook=ALL&page=-1) do Moodle UESB (base da Atividade Avaliativa 3 — Palavras Cruzadas):

Termo / ConceitoDefinição Oficial no Moodle UESB
AcessibilidadeGarantia de que um aplicativo ou site possa ser plenamente utilizado por pessoas com diferentes tipos de habilidades, deficiências ou necessidades especiais.
ANDROIDUma das duas principais plataformas de desenvolvimento em computação móvel.
Android StudioPlataforma de desenvolvimento (IDE) oficial do Google voltada exclusivamente para a criação de aplicativos para o sistema operacional Android.
Arquitetura da InformaçãoPrática de UX que consiste em organizar, estruturar e rotular o conteúdo de um aplicativo de forma lógica para facilitar a navegação e a localização de informações pelo usuário.
Arquiteturas HíbridasArquiteturas que combinam elementos nativos e tecnologias web para oferecer experiências ricas, acessíveis e multiplataformas aos usuários.
BLOCKCHAINTecnologia de criptografia e registro descentralizado usada em aplicativos móveis para garantir transações seguras e dados à prova de violação.
BUBBLEPlataforma No Code que permite a criação visual de aplicativos web e móveis sem codificação, contendo funcionalidades de banco de dados integradas.
CHATBOTSSistemas de conversação automatizados acionados por IA para fornecer suporte ao cliente e interações em tempo real nos aplicativos.
Computação MóvelTecnologia que permite o uso de dispositivos computacionais (como smartphones e tablets) enquanto o usuário está em movimento, proporcionando acesso a uma ampla gama de serviços e aplicativos.
Consistência VisualManutenção do mesmo padrão de cores, fontes, espaçamentos e estilos visuais em todas as telas de um aplicativo para criar uma experiência unificada.
Cores e TipografiaSeleção de paletas cromáticas e famílias de fontes que se alinham com a identidade visual do produto e otimizam a legibilidade do conteúdo textual.
Desenvolvimento Low CodeAbordagem de desenvolvimento que utiliza interfaces visuais e ferramentas gráficas de arrastar e soltar com configurações simples, reduzindo a necessidade de codificação manual.
Desenvolvimento MultiplataformaAbordagem que permite criar aplicativos que funcionam em várias plataformas, como Android e iOS, utilizando uma única base de código comum.
Desenvolvimento No CodeMetodologia de criação de aplicativos que não requer nenhuma habilidade ou conhecimento de codificação, sendo realizada por meio de interfaces totalmente visuais e intuitivas.
Desenvolvimento TradicionalAbordagem de criação de software focada em programação manual, onde desenvolvedores criam algoritmos, estruturas de dados e lógica a partir do zero.
Design de InteraçãoCriação de fluxos e caminhos de interface intuitivos que respondem às ações dos usuários de forma previsível, amigável e altamente eficaz.
Design sem ToqueInterfaces de usuário inovadoras que respondem a gestos, comandos de voz e movimentos corporais do usuário, dispensando o contato físico direto com a tela.
FLUTTERFramework de interface de usuário (UI) de código aberto criado pelo Google para desenvolvimento de aplicativos multiplataforma usando uma base de código comum.
Flutter FlowFerramenta No Code para criar aplicativos móveis de forma totalmente visual, oferecendo controle completo sobre o design e a interatividade.
IDE (Integrated Development Environment)Ambiente de Desenvolvimento Integrado. Um conjunto de ferramentas unificadas (como editor de código, compilador e depurador) que facilita a criação de aplicativos.
Inteligência Artificial (IA)Tecnologia emergente em computação móvel usada para analisar padrões de comportamento, prever necessidades e automatizar tarefas nos aplicativos.
Internet das Coisas (IoT)Rede de dispositivos físicos (eletrodomésticos, câmeras, sensores) que se conectam à internet e podem ser controlados e monitorados através de aplicativos móveis.
iOSUma das duas principais plataformas de desenvolvimento em computação móvel, exclusiva para dispositivos fabricados pela Apple (como iPhone e iPad).
KODULARPlataforma No Code online voltada para a criação de aplicativos móveis para o sistema operacional Android.
LAYOUTOrganização espacial e visual dos elementos de design na tela para criar uma estrutura coesa e intuitiva.
MicrointeraçõesDetalhes de design interativo (como pequenas animações e efeitos táteis) que respondem sutilmente à ação do usuário, fornecendo feedback visual imediato.
Microsoft Power AppsSolução de desenvolvimento Low Code da Microsoft que permite criar aplicativos com facilidade, contando com integração nativa com o Office 365.
OutSystemsUma plataforma líder de desenvolvimento Low Code que oferece criação rápida de aplicativos e facilidade para integração de sistemas complexos.
Pesquisa do UsuárioPilar de UX focado em compreender as necessidades, desejos e comportamentos dos usuários reais por meio de pesquisas, entrevistas e análises de mercado.
Programação ManualPrática clássica do desenvolvimento tradicional onde se escreve todo o código-fonte manualmente, proporcionando flexibilidade total, mas exigindo alto tempo e habilidade.
React NativeFerramenta popular de desenvolvimento multiplataforma que permite aos desenvolvedores criar aplicativos consistentes e eficientes para diferentes sistemas operacionais.
RESPONSIVIDADECapacidade de adaptação de um layout visual de tela para diferentes dispositivos e tamanhos físicos de display, mantendo a consistência da experiência.
Saúde ConectadaIntegração de aplicativos móveis a sensores e wearables de saúde para monitorar dados médicos, atividades físicas e sinais vitais do usuário em tempo real.
SDK (Software Development Kit)Kit de Desenvolvimento de Software. Um conjunto de ferramentas, bibliotecas e ambientes de execução essenciais para criar aplicativos para uma plataforma específica.
Tecnologia 5GRede de conectividade móvel de quinta geração que oferece velocidades de dados ultra-rápidas e latência mínima, permitindo o funcionamento de aplicativos ricos em recursos.
Testes de UsabilidadeAvaliações práticas realizadas com usuários reais para identificar problemas de navegação, gargalos na interface e oportunidades de melhorias no design.
UI (User Interface)Interface do Usuário. O aspecto estético e visual do design que o usuário vê e com o qual interage diretamente, incluindo botões, menus, ícones, cores e tipografia.
USABILIDADEAtributo de qualidade que mede quão fácil, direto e intuitivo é o fluxo de trabalho de um produto digital durante o uso.
UX (User Experience)Experiência do Usuário. Refere-se à percepção e experiência geral que uma pessoa tem ao interagir com um aplicativo ou website, abrangendo utilidade, facilidade de uso e satisfação.
XCODEAmbiente de desenvolvimento integrado (IDE) oficial e obrigatório da Apple para a criação de aplicativos para iOS, macOS e watchOS.
